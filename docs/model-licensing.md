# Model licensing

No third-party model code or weights were downloaded or executed in Phase 1. Therefore there is no approved commercial model and no licensing evidence supporting a production recommendation.

The executable `center-contrast-smoke-test` has no model weights. Its commercial status is explicitly `unresolved; not a production recommendation` because the repository license has not been selected. This avoids confusing a test adapter with a legally cleared product model.

Before adding BiRefNet, RMBG-2.0, U²-Net, MODNet, or SAM, record the exact repository revision, weight file source and revision, code license, weight license, terms, attribution, redistribution requirements, model size, runtime, and commercial-use conclusion. Ambiguous terms are a blocker.
